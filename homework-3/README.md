## Project Structure

```text
kafka-browser-history/
├── data/
│   └── history.csv            # Input dataset (add your own export here)
├── report/                    # Output directory for generated statistics
│   └── top_domains.json         # Auto-generated by the consumer
├── src/
│   ├── consumer/
│   │   ├── __init__.py
│   │   └── main.py            # Kafka consumer and stats calculator
│   └── producer/
│       ├── __init__.py
│       └── main.py            # Kafka producer (CSV reader)
├── docker-compose.yml         # Docker orchestration file
├── Dockerfile                 # Shared Python image build instructions
├── requirements.txt           # Python dependencies
└── README.md                  # Project documentation
```

---

## Prerequisites
To run this project, you only need to have the following installed on your machine:

* Docker
* Docker Compose

---

## Instructions on How to Run

1. Prepare your dataset
Export your browser history to a CSV file. Ensure the file contains a url column. Name the file history.csv and place it inside the data/ directory.

2. Start the infrastructure
Open a terminal in the root directory of the project and run the following command to build the python images and start all microservices (Redpanda, producer and consumer):

```bash
docker compose up --build -d
```

3. View the generated report
The consumer also saves the calculated statistics continuously to a JSON file. You can find the output locally at:

```
./report/top_domains.json
```

4. Clean up
Once the producer finishes streaming and you are done observing the output, tear down the environment gracefully:

```bash
docker compose down
```

---

## Configuration
You can easily adjust the behavior of the application by modifying the environment variables inside the docker-compose.yml file:

* STREAM_DELAY_SECONDS (producer): Controls the speed of the data stream. Set to 0.0 for maximum speed, or a higher value (e.g., 0.5) to visually observe the stream processing in real-time.
* KAFKA_TOPIC: The name of the Kafka topic used for streaming (default: browser-history).
